# Object Oriented Software Development (ENUIC) - Library Management System

This repository hosts the full desktop architecture, software structures, and structural database files designed and implemented for the **Object Oriented Software Development (ENUIC)** core academic model.

##  Project Overview
The primary goal of this platform is to build a reliable, maintainable, and scalable **Library Management System** following strict object-oriented programming (OOP) paradigms. The project handles textbook resource management, user account profiling, lending transactions, and internal status checks.

---

## System Architecture & Code Components

###  Code Solution Layer
* **Visual Studio Solution (`.sln`):** Governs the central decoupling framework, connecting visual dashboard assets directly with underlying controller objects and service modules.
* **OOP Paradigms Applied:** Implements modular classes with strong emphasis on *Encapsulation* (protecting data states), *Inheritance/Polymorphism* (for distinct user or material groups), and *Abstraction* (separating storage logic from interface interactions).
* **Workspace Environments:** Configuration layers mapped cleanly through state caches (`v16/.suo` templates) ensuring IDE environment continuity.

###  Database Tier (`.sql`)
* **File Reference:** `librarymanagementsystem (1).sql`
* **Schema Design:** Structured relation tables mapped to track automated book metadata records, current stock/inventory, borrow tracking, and student account conditions.
* **Integrity:** Enforces relational query structures with primary and foreign key constraints to completely avoid tracking drops.
